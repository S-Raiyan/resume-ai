# ResumeAI

AI-powered resume analyzer that evaluates resumes, gives ATS scores, improvement suggestions, and job recommendations.

## Features
- AI Resume Analysis
- ATS Score
- Resume Improvement Suggestions
- Job Role Recommendations
- Secure Login & Registration

## Tech Stack
Frontend: React + TailwindCSS  
Backend: Node.js + Express  
AI API: Groq (LLaMA)  
Database: MongoDB

## Installation

Client:
npm install
npm run dev

Server:
npm install
npm start
